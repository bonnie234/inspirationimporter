Get started in minutes.

No local server or Terminal is required. The extraction backend is hosted.

  1. Download and unzip the plugin folder.
  2. Open Figma Desktop.
  3. Go to Plugins → Development → Import plugin from manifest…
  4. Select manifest.json.
  5. Run Plugins → Development → Inspiration Importer.
Download ZIP

Known limitation

Some websites block automated extraction or protect individual image assets. If that happens, try another public page or a direct image URL. A blocked site does not necessarily mean the plugin is broken.
